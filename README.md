# Operation Sentinel

A scale-agnostic police personnel scheduling & dynamic deployment platform.

## Features
- Dynamic Zscore-based force distribution
- 30-day / 3-shift scheduling with fatigue awareness
- Real-time incident response cascade and load balancing
- Optimistic Concurrency Control for simultaneous admin operations

## Tech Stack
- Frontend: React (Vite) + Tailwind CSS, React Flow, TanStack Table
- Backend: Node.js + Express
- Database: MongoDB Atlas (Mongoose) with transactions
- Real-time: Socket.IO

## Getting Started

### Backend
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
